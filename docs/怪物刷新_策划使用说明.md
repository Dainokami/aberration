# 怪物刷新：策划使用说明

2026-10-18更新：普通怪改为固定刷新点，每点30秒周期，地图编辑与世界生成共用相邻格编辑。

## 开始使用

1. Godot 顶部点击「关卡编辑器」，在末尾打开「怪物」页。
2. 勾选「启用本地图怪物刷新」。旧地图默认关闭。
3. 点击「新增刷新点」，在真实地面或水面左键点击第一格，沿同一高度层的相邻格拖动扩展。新点未绘制时只是草稿。
4. 为点命名，设置存活上限（默认2只）。选中范围为金色，其他点为紫色；选择模式点击范围选点，擦除模式移除边缘格，删除按钮移除整个点。保存地图，再「保存并试玩」。
5. 试玩中 WASD 移动、Space 跳跃、K 攻击怪物、E 拾取掉落或进入 Boss 门。J 仍用于破坏场景物件。

直接演示：打开 `scenes/monster_spawn_points_demo.tscn` 按 F6。编辑示例：打开 `scenes/monster_spawn_points_editor_demo.tscn`，选择 TerrainBuilder 后打开「怪物」页。两者共用新地图 `data/levels/monster_spawn_points_demo.tres`；原有地图未改写。

示例是32×32格，包含草原、岩石、沙漠、水面各一个双格点，普通怪30秒，精英/Boss为300/600/900/1200秒。

## 配置

| 项目 | 默认 |
|---|---|
| 普通怪 | 每点每30秒补充1～2只，默认最多存活2只 |
| 刷新位置 | 点中实际合法格中心，依据该格地形筛选物种 |
| 激活 / 追踪范围 | 以相邻格平均中心为圆心；0自动，相机可视地面范围+4m |
| 精英1 / 精英2 | 300 / 600 秒，暂用猩猩 / 荒原狼 |
| 精英倍率 | 生命 3×、伤害 1.5× |
| 条件 / 强制 Boss | 900 / 1200 秒 |
| 最终安全半径 / 雾速度 | 30m / 3m/s |
| 玩家生命 / 玩家雾伤害 | 100 / 5每秒 |
| 怪物雾伤害 | 100每秒 |

「更多设置」默认折叠，包含怪池、数量、性格、区域及精英/Boss。普通怪的允许地形严格读取设计表，不需要输入英文；可调启用、权重、生命、伤害、移速和攻击间隔。精英地形用中文选项。

| 地形 | 设计表物种 |
|---|---|
| 草原 | 荒原狼、袋鼠、恶魔犬、长臂猿、鹅、章鱼 |
| 岩石 | 长臂猿、猩猩、蝙蝠、信天翁 |
| 沙漠 | 鸵鸟、沙鼠、老鹰 |
| 海洋 | 鹅、章鱼、食人鱼、水蛇 |

食人鱼、水蛇因缺美术不可选；信天翁、老鹰已在 2026-10-20 补齐。一个点可以覆盖相邻的不同地形格，每只怪按最终落脚格判断。点之间不可重叠；擦除不能拆开点，需从边缘擦或另建点。删除地块自动清理该层落脚格，若分成多段则保留为多个点，整个操作支持撤销。上方覆盖只隐藏下层点，不删除记录。

「激活/追踪半径」填0时自动：按实际试玩相机的视锥与有限地图地面求交，取玩家到可视边界的最远水平距离再加4m；浅俯角前后视距不同，故圆形范围取最远侧。填写米数可固定范围。编辑器金色圆圈展示范围（自动圈按默认相机预估，试玩按实际镜头更新）。范围内才能计时刷怪与追踪；离开暂停计时，怪物取消攻击返回出生格，回来继续计时与追踪。受击不会扩大追踪圈。

已激活且有怪物的画面外点会在屏幕边缘显示紫色「怪物动静」方向提示，引导探索；进入Boss阶段后由Boss门指引接替。

## 世界生成中的刷新点

特殊地图和预制保存刷新点。捕获选区须完整包含点；生成时同步旋转、平移及高度对齐，多份预制各有独立ID。刷新使用最终世界怪池，源地图文件不改写。

世界生成窗口的「小怪刷新点」页：先生成预览，再新增、选择、绘制、擦除或删除，操作与地图编辑相同。右侧二维图定位最高外露面，应用后可在3D中编辑低层点。页面提供撤销/重做及全局启用开关，应用不会丢失点或生成界面配置。

新增/修改/删除随生成配方保存，固定种子可复现。修改种子、尺寸或源地图后会重新校验手工点；若位置无地块，明确报错，请恢复参数或「清除配方中的点修改」再生成。示例配方：`data/worldgen_spawn_points_recipe.tres`，含两份带守卫点的草原营地。

默认全部主动追踪。勾选「按设计表性格」后，原表非主动怪受玩家攻击后再追踪。原表成群信息保留为元数据；每次数量仍遵循本次最新要求的 1～2。

试玩 HUD 的 1×/10×/60×仅加速刷新时间轴，不加速 AI、移动、物理、雾或伤害。该选项不保存到地图。

## 区域画笔

打开「绘制区域」，选择探索、静止、禁刷、恢复默认或清除禁刷，用左键拖动，支持 1×1、3×3。

只能绘制真实外露顶面，按 `(X, 支撑层, Z)` 保存。上下层独立，负坐标扩图不会移动已有标记。静止与禁刷独立：静止区暂停探索计时，禁刷区只限制新敌人生成。恢复默认会清除该格手绘覆盖及禁刷；清除禁刷会保留探索/静止标签。

半透明覆盖中：橙红为探索、青绿为静止、红为禁刷。覆盖仅用于编辑，没有碰撞，不随场景保存为节点。配置与每笔绘制都支持原生撤销/重做。

世界生成的功能区作为默认标签，手绘覆盖优先。无生成标签的手绘地图默认探索。预制保留区域与点，不携带整图怪物配置；世界生成结果保存自己的刷新配置。

「检查出生点候选圆环」显示所选物种的合法格中心，检查实际区域、生态、净空、物件体积与导航连通分量。运行时另加实时物理占用检查。

## 战斗循环

玩家取得控制后开始累计探索时间。静止区暂停但不重置；怪物仍可进入静止区追踪和攻击。

普通点与精英事件独立。取得控制且玩家在激活范围内才累计该点30秒周期；离开范围暂停、不清零，返回续计。静止区不暂停普通点计时，禁刷点不刷新。没有空闲合法格则跳过，下个周期重试。每点按稳定ID统计存活怪物，回点仍占名额，死亡后下一周期补充。没有点时不刷新普通怪。

普通点须符合实际地形、移动方式、阶梯、净空、障碍和实时物理占用；不要求与玩家连通或位于圆环。精英保留探索区、玩家可达及9～12m圆环约束。

导航按实际地形分层、净空、阶梯和物件碰撞构图。陆生不进入水块；两栖可沿水岸接水面；飞行有独立高度。路径不受刷新范围限制，每0.1秒分批刷新最多4个追踪目标。怪物追踪、攻击与掉落沿用现有机制。

15分钟后，两次精英都由玩家击杀则生成唯一 Boss 门；15分钟后才补齐击杀也立即满足条件。环境/浓雾死亡不算玩家击杀。20分钟强制请求门。门点无效时保持待生成，继续原刷新规则，成功后停止追加敌人，已生成敌人继续行动。

门从全地图可达探索区选择合法地面位置。玩家旁的黄色箭头随相机与门位置更新。靠近按 E：配置 `res://...tscn` 目标后切换；空白显示「未配置 Boss 目标场景」，保留控制。

雾从地图最远角的覆盖半径向门收缩，正常时间每秒3m，最后30m。屏幕深度重建实际物体世界位置后按水平距离显示雾，伤害使用同一中心/半径；楼层和跳跃不提供免伤。玩家死亡停止战斗循环，重新试玩开新一轮。

## 美术和掉落

目前12类已有美术。2026-10-20 狼、鸵鸟、沙鼠、长臂猿、猩猩、信天翁、老鹰替换为机械造型并接入移动、攻击、死亡动画；狼为4帧，其余六种为8帧。袋鼠、恶魔犬、鹅、章鱼、蝙蝠沿用旧资产。食人鱼、水蛇仍因缺美术默认禁用。已有地图中明确关闭的信天翁、老鹰不会自动开启，需要在怪物页启用。

源件复制到 `assets/source_art/monsters_20261018`，派生PNG及分件在 `assets/derived_art/monsters_20261018`。manifest记录档案哈希、画布、裁剪、分件；`source_trace.json`补充逐成员路径、哈希和原样复制校验。原 ZIP、设计表及原图不修改。

上述路径保留旧包；新机械造型的源图、透明图和动画目录、来源哈希及接入说明见 `docs/机械小怪_接入与验收.md`。新图使用固定相机精灵与轮廓投影，移动时水平翻转，攻击关键帧对齐原伤害时点。狼不做程序摆动，使用独立四帧动画。旧物种继续沿用原有表现。

玩家击杀掉落映射到现有部件ID，并通过 E 放入轻量 `scene_inventory`。本轮未扩展背包UI、自动装配或养成。门体为程序化替换入口，鸟妖完整两阶段 Boss 战不在本轮范围。

## 验证与限制

- 刷新点专项、真实编辑器输入/撤销/保存、世界生成界面及旧怪物战斗回归记录见 `docs/小怪刷新点_验收.md`。
- 20分钟压力脚本保留240只普通怪及两精英，无隐藏上限；240次缓存A*请求合计约13ms（本机实测）。这是保留怪物的时间轴与导航压力测试，不等同242只动态AI同时渲染的帧率指标。
- 世界生成、接缝、分层、物件、海洋资产、玩家形象、相机、原编辑器与世界生成对话框回归通过。旧保存失败测试的故意错误单独保留。
- 后续 `fix/swimming-chunk-collisions` 已修复流体标签优先级，鱼尾实际水面/水下速度5m/s；完整 `test_editor_play.gd` 通过，测试等待改用物理帧。
- 32×32真实Metal自动渲染及逐图检查完成，截图位于项目上级 `怪物刷新_验收截图`。桌面工具人工输入覆盖与自动输入分别记录，不将静态截图当作完整手工流程通过。
- 后续碰撞按8×8区块及高度层共享物理体，64×64/96×64混合生成世界分别为472/571个碰撞对象，已完成实际构建与刷怪；Jolt上限未提高。600×600编辑边界不代表满图战斗性能验收。
- 怪物导航针对地图地形和记录中的物件体积，实时生成检查再验证物理占用；任意外部移动平台与空中绕高墙的完整3D导航不在本轮范围。
