## 实施

1. 海水作为独立层记录，与空气和陆地实体区分，新增水体查询 API；不再把水面写到陆地顶面。支持单击空地、贴面堆叠、删除、保存、预制和旧数据迁移。原海底地形独立保留。
2. 海水体积不创建固体阻挡；水面与水中分开，水体提供流体检测，陆地边界按真实陆地占用生成，水体不会遮掉水下物件或生成岩壁碰撞。普通实体和水体不能在同一槽冲突。
3. 新 1016 pack 独立 ID、manifest、参数和 SHA-256；图片保持透明、比例和原色，原图不覆盖。每张图均进入可搜索物件库，精确保存生态、类别、布局、米制碰撞/触发区、原图/表格行及视图。
4. 果树的实体碰撞按表格三格 L 形，艺术画面规格与碰撞分开；可进入区域使用触发区，不使用固体阻挡覆盖整个图片。
5. 限定生态与支撑：草原荆棘/果树、沙漠流沙、草原/岩石藤、海洋气泡（海底真实陆地支撑）、岩石/海洋资源；遗骸和宝箱的各生态变体按其图案对应分类。
6. 验证每图哈希、分类与参数、实际场景节点和材质、支撑/生态拒绝、撤销/保存重载/预制、独立海水拾取与渲染及物理。生成逐件验收表。
7. 提交仅本 worktree 完成的任务变更。合并前读取主仓库最新状态；其他 agent 仍有未提交变更时不得强行切分支或覆盖文件，采用可验证的变更集集成并保留所有并行工作。
