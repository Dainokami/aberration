# 小怪刷新点与激活范围验收

2026-10-18。Godot 4.7.2，Metal Forward+，Apple M5 Pro。分支 `feat/monster-spawn-points`。

## 最终行为

- 地图保存相邻、同层的刷新格组、稳定ID、名称、启用、存活上限和激活/追踪半径。普通怪每点30秒补充1～2只，默认存活上限2。没有刷新点不刷普通怪。
- 只有玩家进入以格组平均中心为圆心的范围才累计该点计时；离开暂停，回来续计。半径0自动：实际相机视锥与有限地图地面求交，取可视最远水平边界并加4m；可手填米数。
- 普通怪严格按实际落脚地形及设计表物种生态筛选，检查移动方式、禁刷、阶梯、障碍、物理占用。静止区不暂停普通点，精英/Boss仍使用探索时间。
- 怪物追踪与攻击使用同一点中心和半径；离开取消攻击并回到原出生格，受击不能扩大追踪，远程投射物不伤害范围外玩家。画面外激活且已有怪的点显示紫色方向提示，Boss门出现后由门指引接替。
- 编辑器怪物主页为点操作；怪池与精英等折叠。地图/世界生成复用同一新增、选择、绘制、擦除、命名、上限和半径控件。点与圆形范围可见，撤销/重做、资源保存重载保留数据。
- 特殊地图点完整捕获，旋转/平移/高度对齐同步，多份各有独立确定性ID。配方保存新增、修改、删除；生成后应用保留点和配置。

## Metal窗口与实际输入

- 桌面鼠标点击“新增刷新点”并拖动两格，画面出现两个金色落脚格；Command-Z撤销移除范围。操作在新示例地图内存副本完成，未保存覆盖源地图。
- Metal世界生成窗口成功显示两份草原营地及其点；二维鼠标编辑和应用保存由真实EditorPlugin自动输入套件验证。
- Metal运行专项实际刷新6只怪，精英击杀后生成Boss门及浓雾；新范围专项确认刷新点不在屏幕内但激活为真，实际生成怪物并显示紫色“怪物动静”提示。此场景自动半径约50.7m（随视口、镜头和地图位置变化），不是固定距离。
