# 环境光照与阴影

2026-10-19，Godot 4.7.2 / Metal Forward+。

## 运行效果

游戏现在使用暖色主光和略冷的环境补光。地形、台阶、悬崖与物件接收光照；树木、岩石、台地、角色和怪物能在地面形成实际阴影，接触遮蔽补充台阶缝和物件落点。

角色和怪物的原画已有面部、躯体明暗，所以保持原画亮度并投出透明轮廓阴影，避免背光时人物整体变灰。地面保持高粗糙度、关闭镜面高光。水体继续使用原透明表现，泡沫、地面贴花和细节不新增大面积投影。

编辑器仍显示素材固有色。运行时复制材质与缺少法线的网格，保留纹理、UV、地图色调、透明轮廓、原始资产和地图资源。关卡切换会沿用当前光照配置。

## 调整参数

在Godot文件系统选中 `data/environment_lighting_profile.tres`，即可在检查器中调整。`scenes/level_playtest.tscn`对应脚本的 `lighting_profile` 默认引用它；置空后可运行原始光照基线，便于比较。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| ambient_color / ambient_energy | 冷浅灰蓝 / 0.62 | 暗部补光，保留阴影中的原画细节 |
| sun_color / sun_energy | 暖米白 / 0.78 | 主光颜色与强度 |
| sun_rotation_degrees | (-55, 135, 0) | 固定相机下清晰可见的侧向投影 |
| sun_angular_distance | 1° | 主光柔影 |
| shadow_distance | 80米 | 四级阴影覆盖距离，远处渐隐 |
| shadow_opacity | 0.85 | 阴影强度 |
| shadow_bias / shadow_normal_bias | 0.02 / 0.35 | 降低自阴影条纹，同时避免影子明显离地 |
| contact_occlusion | 开启 | 轻微屏幕空间接触遮蔽 |
| occlusion_radius / occlusion_intensity | 1米 / 0.8 | 接触遮蔽范围与强度 |

原有美术相机、96米可视距离、72米起深度雾和区块加载策略继续沿用。`data/color_grade_profile.tres`负责后期调色，本轮没有修改它。

## 实现与兼容

- `scripts/assets/environment_lighting_profile.gd`统一环境光与太阳配置。
- `scripts/assets/runtime_lighting.gd`处理运行材质、法线和阴影。只缓存少量Shader程序，不缓存已卸载区块的材质、纹理和网格。
- `TerrainBuilder`在区块发布、物件实例化、细节刷新和切片时应用配置，之后新加载的区域也能受光。
- 有遮挡淡出的物件在进入场景前应用材质，避免淡出脚本持有失效材质。仅投影的 `LightingShadow` 子节点共用原网格，透明裁剪后投影；物件移动、隐藏和卸载同时作用于影子。
- 采集、宝箱开合、藤蔓与掉落的原有状态逻辑不变，运行中新生成的机制物件也应用光照。

## 验证

`tests/render_environment_lighting.gd`生成同机位的修改前、修改后、关闭SSAO、关闭主光阴影、关闭单棵树投影的画面。测试通过图像差异验证光照确实作用于画面，而非只检查开关。

最终暂存副本实测：主光阴影使约13,106个像素明显变暗，接触遮蔽在约2,291个像素上产生轻微变化；独立枯树阴影约1,048像素，填充率约45%，验证了枝叶透明轮廓而非矩形投影。共享资产材质、淡出引用和隐藏时影子的生命周期检查通过。

1280×720固定48×48画面，修改前帧时间中位数约8.47毫秒，修改后最终副本约8.66毫秒；P95约8.64/9.02毫秒。该数据受刷新同步和机器负载影响，不能解释为阴影没有GPU成本。

最终暂存副本200×200真实试玩行走测试：首屏64个区块完整预载，启动约5.8秒，帧时间中位数16.5毫秒、P95约26.6毫秒、最大38.3毫秒。新加载区块继续受光，怪物休眠恢复仍保留投影，行走/刷怪/重置/传送通过。区块52项、编辑器11项、原素材46项、玩家形象7项、传送50项、游泳2项及V2数据回归均通过。

## 已知边界

这是针对当前固定相机的实时光照，单视角图片投影仍是原图片载体的轮廓，不会生成不存在的枝干厚度或物件背面。阴影只覆盖近处80米并渐隐，SSAO受屏幕中可见几何限制。正式视觉验收使用Metal Forward+，未验证移动端、低端GPU或兼容渲染器；600×600高密度战斗的完整光照负载也未覆盖。
