# 倒计时传送门

开发位置：`aberration-countdown-portal` worktree，分支 `feat/countdown-level-portal`。本功能接入现有地形编辑器和默认试玩入口。

## 快速试玩

在这个 worktree 的 Godot 项目中打开 `scenes/portal_demo.tscn`，按 F6 运行当前场景：

1. 画面顶部显示 5 秒倒计时。
2. 结束后，玩家附近出现青蓝色发光门框。
3. WASD 移动到门附近，出现“E 进入下一关”后按 E。
4. 进入沙漠地面的演示终点 `portal_destination_demo.tres`。终点已关闭自动传送。

也可以在终端执行：

```sh
"/Users/bytedance/Desktop/godot/godot-engine/Godot.app/Contents/MacOS/Godot" \
  --path "/Users/bytedance/Desktop/godot/aberration-countdown-portal" \
  --scene res://scenes/portal_demo.tscn --rendering-driver metal
```

普通地图通过“保存并试玩当前地图”或默认 F5 入口运行，缺少新配置时默认倒计时为 **60 秒**。演示场景的 5 秒是演示地图自己的设置。

## 策划配置

打开顶部“关卡编辑器”，选择末尾的 **流程** 页。窄 Dock 中使用页签左右箭头滚动到“流程”。

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 启用倒计时传送门 | 开启 | 关闭后不显示倒计时、不生成门，可用于终点关卡 |
| 倒计时 / 秒 | 60 | 可设 0.1–7200 秒 |
| 目标地图 | `res://data/levels/portal_destination_demo.tres` | 选择已有的 LevelData `.tres` 地图；需要合法出生点 |
| 生成最近距离 / 米 | 4 | 最小允许 2 米 |
| 生成最远距离 / 米 | 8 | 不小于最近距离，最大允许 32 米 |

可用“选择目标地图…”或填写路径；填写后回车或离开输入框即应用。修改支持原生撤销、重做和保存重载；切换地图不会串写配置。世界生成结果继承当前地图的流程配置，预制片段不携带整关流程。

旧地图打开时只在内存采用默认值，不因打开而重写资源。用户修改配置并保存后，新字段随地图持久化。

## 运行规则

- 地形、角色、相机初始化完成后开始计时。游戏暂停时暂停计时，站立或进入怪物时间静止区仍继续。
- 归零后按玩家当时的位置搜索；只在附近可达、有真实实体支撑、门框净空足够的地面生成一个门。生成后固定位置。
- 障碍、不同楼层、阶梯、空洞和水体参与检查。玩家在空中、水中，或附近没有满足距离与净空条件的地面时，显示“正在寻找传送门位置”，每秒重试。移动到开阔地面即可继续。
- 靠近至 2.5 米内且没有实体遮挡时才可按 E。碰触不会自动切关；切换中禁止重复触发。
- 目标地图的资源类型、出生点和地图内容通过校验后才切换。错误目标保留原关卡和传送门，显示错误原因。
- 切关保留现有试玩角色的下肢选择、攀爬能力、生命、氧气和采集背包，清空速度、攀爬状态及旧场景引用。新地图使用自己的流程设置。
- 玩家死亡后停止流程和传送交互；R 仍是现有“回出生点”，不会开启新一轮倒计时。
- 现有 Boss 门、探索计时、浓雾和普通怪机制保持独立。新门可交互时优先响应 E；不在新门范围内仍走原交互路径。

## 后续 UI 和美术接入

- `scripts/level/level_transition_config.gd`：地图级配置。
- `scripts/runtime/level_transition_controller.gd`：计时与状态管理；`status_changed(remaining_seconds, state)` 向 UI 发出更新，`transition_requested(target_level)` 请求切关。
- `scripts/runtime/level_transition_hud.gd`：当前临时顶部文字。正式 UI 可订阅控制器信号并替换该节点。
- `assets/placeholders/level_portal.tscn`：当前门框占位场景。落点在根节点，当前净空尺寸为 `1.8 × 3.2 × 0.7` 米；换美术时同步核对 `LevelPortalPlacement.PORTAL_SIZE`。
- `scripts/runtime/level_playtest.gd`：保留统一 TerrainBuilder 加载流程；显式指定目标，不修改编辑器的 `user://terrain_playtest.cfg`。
