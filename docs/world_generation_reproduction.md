# 复现场景：用三张手工地形生成一张探索地图

策划已经制作了「草原高台、石板遗迹、沙地绿洲」三张 16×16 格的小地图，希望每种出现一次，自动生成周围的草原、岩石、沙漠和海洋，连接出生点与特殊地形入口，并散布物件。最终交付一张 64×64 格（128×128 米）、可以继续手工编辑和保存的完整地图。

本说明对应修正空隙、高度对齐和固定视角物件朝向后的算法版本 4。2026-10-18 已在 Godot 4.7.2 下实际生成并点击「应用为新地图」：结果为 3 个特殊地形、37 个物件、100 格通路，三张特殊地图的接入地面均与大地图齐平。特殊地图原有地面在第 0 层，投放时整体上移到第 1 层，顶面为 4m；内部高台仍保留原有高差。自动散布的伪 3D 物件保持美术原始方向，不再随机转出纸片侧面。

**1. 准备工程与三张源地图**

用 Godot 4.7.2 打开 `aberration/project.godot`，等待资源导入完成。初版已通过 [PR #7](https://github.com/Dainokami/aberration/pull/7) 合并；本说明还要求当前 `fix/worldgen-prefab-seams` 分支的空隙与高度修复，尚未提交上传。旧主分支只有初版行为。

最快路径：打开「世界生成…」→「加载配方…」选择 `res://data/worldgen_three_landmarks_recipe.tres` →「生成预览」→「应用为新地图」。以下步骤用于手动填写同一配方。

本次直接复用已随仓库提交的三张地图，以保证与展示结果一致：

| 添加顺序 | 特殊地形 | 文件路径 |
| --- | --- | --- |
| 1 | 草原高台 | `res://data/levels/special_grass_plateau.tres` |
| 2 | 石板遗迹 | `res://data/levels/special_stone_ruins.tres` |
| 3 | 沙地绿洲 | `res://data/levels/special_desert_oasis.tres` |

三张均为 16×16 格。复现时保留原文件内容和上述添加顺序；同一种子还依赖相同的参数、算法版本和物件资产。重新手绘一张外观相似的地形，可以验证同一工作流程，但不属于逐格一致的复现。

需要先查看源地图时，点击顶部「关卡编辑器」，再用插件文件区的「打开」选择其中一张；查看完直接进入下一步。

**2. 打开世界生成，填写“世界”页**

点击顶部「关卡编辑器」→ 右侧文件操作区下方「世界生成…」。顶部入口会自动打开或复用编辑工作区并选择 TerrainBuilder。

| 参数 | 本场景填写值 |
| --- | --- |
| 随机种子 | `1692031905` |
| 宽 / 格 | `64` |
| 高 / 格 | `64` |
| 生态区域数 | `12` |
| 边界起伏 | `0.22` |
| 草原权重 | `4` |
| 岩石权重 | `3` |
| 沙漠权重 | `2` |
| 海洋权重 | `1` |

输入数值后按 Enter 确认。宽高下面应显示「128×128 米 · 4096 格」。本轮不要点击「换一个种子」。

**3. 填写“功能区”页**

| 参数 | 本场景填写值 |
| --- | --- |
| 出生核心半径 / 格 | `6` |
| 静止核心数 | `3` |
| 静止核心半径 / 格 | `9` |
| 距离衰减 / 格 | `8` |
| 采集物 / 千格 | `6` |
| 环境物件 / 千格 | `3` |
| 资源簇间距 / 格 | `9` |
| 簇内物件间距 / 格 | `2` |

这些参数控制出生点周围净空、静止区域和物件散布。本场景的静止区是生成标签，尚不触发正式游戏里的计时暂停。

**4. 填写“特殊地块”页**

总预算填 `6`，最小间距填 `3`。如果列表里已有其他来源，先点击对应「移除」，然后按第一步的顺序添加三张源地图。

每次点击「添加已保存地图 / 预制…」，进入 `res://data/levels/` 选择对应 `.tres`。添加后每项都设置为：

| 参数 | 三张地图统一设置 |
| --- | --- |
| 至少 | `1` |
| 至多 | `1` |
| 权重 | `1` |
| 区域 | 任意区域 |
| 旋转 | 勾选；来源含固定视角物件时会自动显示「固定朝向」 |
| 融合外缘 | 勾选：外围未绘制空白沿用大地图地面 |
| 地面齐平 | 勾选：整体对齐到大地图地面，内部高差不变 |

列表最终应只有三项，每项显示「16×16 格」。总预算 6 是上限；由于每种最多 1 份，本轮只会投放 3 份。此前 UI 讲解中的预算 3 是入门建议，这里采用成品配方实际记录的 6。

**5. 生成，并核对结果**

点击「生成预览」，等待出现「生成成功 · 校验通过」。此时地图仍在生成窗口中，尚未应用到 3D 编辑区。

| 检查项 | 预期结果 |
| --- | --- |
| 尺寸 | 64×64 格 / 128×128 米 |
| 种子 | 1692031905 |
| 特殊地块 | 3 |
| 物件 | 37 |
| 通路 | 100 格 |
| 静止区 | 17.6% |
| 应用按钮 | 「应用为新地图」可点击 |

在右侧下拉框切换「生态预览」「功能区预览」「通路预览」。白点是出生点，白框是特殊地形范围，金线是通路及入口。

以预览左上角为坐标原点，横向向右、纵向向下，可进一步核对：

| 内容 | 位置 / 范围 |
| --- | --- |
| 出生点 | `(32, 32)` |
| 草原高台 | 左侧偏下，矩形起点 `(4, 33)`，大小 16×16 |
| 石板遗迹 | 上方偏左，矩形起点 `(15, 3)`，大小 16×16 |
| 沙地绿洲 | 右上方，矩形起点 `(40, 12)`，大小 16×16 |

金线应连接出生点与三个特殊地形的入口。通路校验针对入口可达性；特殊地形内部的孔洞、高台和玩法路线保留作者设计。外围未绘制空格不清空大地图，基准地面与世界齐平。草原外围和沙地都在第 1 层（4m），只有中央手工高台升高到第 2 层（6m）。

下面是修正后的实际生成预览；耗时受机器影响，不作为复现判定条件。初版的 108 格道路与沙地绿洲位置不再作为当前版本预期。

**6. 保存配方，应用并保存地图**

1. 在生成窗口点击「保存配方…」，例如保存为 `res://data/three_landmarks_recipe.tres`。它保存生成设置和源地图路径；下次用「加载配方…」读取后仍需点击「生成预览」。
2. 点击「应用为新地图」。窗口关闭，生成结果进入真实 3D 编辑器，显示为未保存地图。
3. 用「俯视」检查三个特殊地形的位置，用「2.5D」检查高差和边壁。鼠标滚轮缩放，WASD 平移；全图布局以生成窗口中的预览为准。
4. 点击插件文件区的「另存为」，例如保存为 `res://data/levels/repro_three_landmarks_64.tres`。该名字是建议的新输出路径。
5. 使用同一文件区的「打开」重新选择刚保存的文件，确认三块特殊地形和物件仍在。

“保存配方”和“保存地图”是两项不同操作。不要把最终地图另存到三张源地图的路径上。若要验证应用撤销，可在刚应用后、编辑器视口获得焦点时按 Cmd+Z，再按 Cmd+Shift+Z 重做，然后继续另存。

**7. 复现判定与差异处理**

达到第 5 步的统计结果，三个特殊地形位置一致，且应用、另存、重开成功，即完成此场景。

- 结果不同：先核对种子、全部参数、来源顺序、是否重复添加地图，再检查源地图和物件资产是否被修改。
- 「应用为新地图」变灰：参数发生了变化，重新点击「生成预览」。
- 找不到源文件：确认添加的是项目 `data/levels/` 下的三张源地图，而非生成配方或最终世界地图。
- 本复现场景固定使用64×64以保留布局验收基准。2026-10-18已将地形碰撞按区块及高度层合并，另行验证96×64混合地图低于Jolt上限；扩大尺寸会改变本场景的生成结果。

若要演示“同一批手工地形生成另一张世界”，完成上述复现后只修改种子，再生成预览即可。这是同一流程的变体，此时位置、物件数量和道路数量可以变化，不再按本表的固定结果判定。
