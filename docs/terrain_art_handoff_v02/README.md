# 地形图片与接入验证包 v0.2

先双击 `preview.html` 看合并后的离线预览，再读 `USAGE.md` 导入引擎。

- `assets/`：67 张推荐 PNG，包含 11 张地形纹理/透明条、47 张规整遮罩、9 张不规则风格小样。
- `reference/`：旧版锐利收边、遮罩对照和网页投影效果参考，不自动导入为正式资源。
- `spec/manifest.json`：所有推荐图片的尺寸、世界周期、alpha 边界、稳定 ID 与 SHA-256。
- `spec/height_profiles.json`：草地外悬、岩沙内退的横截面参数。
- `preview_scripts/`：离线绘制示例；网页、脚本与 PNG 需保持相对目录一起转发。
- `checks/verification.json` 和 `SHA256SUMS.txt`：完整性记录。

不规则遮罩目前仅三类 × 三变体；其余拓扑使用规整版回退。网页默认显示本轮认可的钝化崖顶。未包含 Godot 场景或引擎集成验收，请程序优先复现独立测试场景。

交付日期：2026-10-12。没有修改原始 PNG、项目相机、地图或运行时代码。
