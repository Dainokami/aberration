# 十种小怪动画索引

每种小怪均有行走、攻击、死亡动画，Godot 打开工程后可直接加载对应的 `SpriteFrames`。

| 小怪 | 动画资源 |
| --- | --- |
| 章鱼 | `res://assets/derived_art/small_monsters/sprite_frames/octopus.tres` |
| 蝙蝠 | `res://assets/derived_art/small_monsters/sprite_frames/bat.tres` |
| 恶魔犬 | `res://assets/derived_art/small_monsters/sprite_frames/demon_dog.tres` |
| 大鹅 | `res://assets/derived_art/small_monsters/sprite_frames/goose.tres` |
| 袋鼠 | `res://assets/derived_art/small_monsters/sprite_frames/kangaroo_front.tres`、`kangaroo_side.tres` |
| 沙鼠 | `res://assets/animations/new_monsters/sprite_frames/gerbil.tres` |
| 狼 | `res://assets/animations/new_monsters/sprite_frames/wolf.tres` |
| 猩猩 | `res://assets/animations/new_monsters/sprite_frames/gorilla_front.tres`、`gorilla_side.tres` |
| 长臂猿 | `res://assets/animations/new_monsters/sprite_frames/gibbon.tres` |
| 鸵鸟 | `res://assets/animations/new_monsters/sprite_frames/ostrich.tres` |

袋鼠、猩猩分别有正面和侧面视角，因此十种怪物对应十二份 `SpriteFrames`。旧五种的小怪动画场景和预览位于 `assets/derived_art/small_monsters/`；新五种的分层场景、原始分层图和预览见 `assets/animations/new_monsters/README.md`。
