## 写入范围

- 地图实验的工具、参数、数据、预览、说明、日志、缓存、测试资源与场景均放在 `personal_workspace/shutiao_map/` 内。
- 允许读取目录外的公共代码、数据与设计资料；默认不得修改目录外的文件。
- 不修改公共 `project.godot`、插件、相机配置、共享地图或资源；不修改其他协作者的未提交内容。
- 若实现确实需要改目录外的内容，先说明具体文件、原因与影响，取得用户明确同意后再执行。

- 不进行 Git 提交，除非用户另有明确要求。
